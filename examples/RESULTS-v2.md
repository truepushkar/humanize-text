## Reading of results

ZeroGPT is a noisy instrument: run-to-run swings of tens of points are common
on borderline prose (T1 v1: one UI run 42.3%, one API run 42.3%, but earlier
UI run 63% on the same text class; T3 v1: 63% vs 54.7% on near-identical text).
Take the following as directional:

1. Both v1 and v2 rewrites consistently land in "Likely Human" or "Human"
   territory — vs 100% AI for both raw inputs (T1, T3).
2. v2's structural-tell checklist did not move ZeroGPT's needle materially on
   these three samples. Expected: ZeroGPT weights n-gram/perplexity features
   more than the discourse-level tells the checklist targets.
3. The checklist is still valuable for actual human readers: it kills the
   "not X but Y" crutch, dramatic closers, and forced triads that human readers
   read as AI giveaways even when detectors don't.
